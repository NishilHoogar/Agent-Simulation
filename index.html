Q-Learning: The Pathfinding Agent

How the Agent Learns

  • The Goal (Green Square): Reaching this tile rewards the agent with +10 points.
  • The Step Penalty: Every move costs -1 point. This teaches the agent that efficiency is key; it must find the shortest path.
  • The Memory (Q-Table): A mental map where the agent scores every move. Over time, it learns which tiles lead to the goal.
  • Exploration: 20% of the time, the agent moves randomly. This ensures it doesn't get stuck in a "good enough" routine and keeps looking for better paths.
